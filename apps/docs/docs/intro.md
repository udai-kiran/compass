# Compass (PennyPilot)

Compass is a self-hosted personal finance application for the Indian context (INR, paise, TDS/EPF payslips, mutual fund folios). Track budgets, transactions, goals, investments, and net worth with full data ownership.

The app is fully functional with AI disabled; the optional AI module powers transaction categorization suggestions, a chat assistant, monthly summaries, and email extraction.
