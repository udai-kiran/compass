`holdings` + `holding_valuations`: stocks, mutual funds, ETFs, gold, FDs, EPF, PPF, NPS. Manual price/value updates (self-hosted: no market-data dependency in v1). Buy/sell/dividend entries.

## Acceptance criteria
- [x] CRUD for holdings and valuation history
- [x] Cost basis, current value, unrealized P&L computed
- [x] Dividend log feeds income reporting

## Implementation
- `holdings`, `holding_valuations` (unique per holding+date, upsert), `holding_events` (buy/sell/dividend) — migration 0006. `asset_class` enum covers stocks/MF/ETF/gold/FD/EPF/PPF/NPS/other.
- `services/holdings.ts`: CRUD, `setValuation` (upsert), `addEvent`/`deleteEvent`, `getPortfolio` (per-holding cost basis = Σbuys−Σsells, current value = latest valuation or cost fallback, unrealized P&L, dividends; allocation by class; 24-month invested-vs-value growth), `portfolioValue(asOf)` for net-worth backfill.
- `routes/holdings.ts`: GET `/api/portfolio`, holdings CRUD, `PUT /:id/valuation`, event add/delete. Registered in `app.ts`.
- Verified: invested ₹1,50,000 → value ₹1,70,000 → unrealized +₹20,000, dividends ₹300, allocation + 3-month growth series.
