Turn free text ("2kg atta, milk 1L, 6 eggs, dal") into structured `(item, qty, unit)` rows using the existing AI path — `createAiProvider` → `chat({ tools: [SPEC], toolChoice: SPEC.name })` → filter tool calls by exact name → Zod `safeParse`.

Reuse the extractor's discipline verbatim: gate structured output on `ai.name !== "ollama"` with a prose `extractJson` fallback, **fail closed on 2+ matching tool calls**, and never crash on unparseable output — return nothing and keep the raw input for replay. Recipe → ingredient list is the same call with a different prompt.

Adds a new `ai_events` kind (the enum in `packages/shared/src/schemas/ai-events.ts` is closed).

## Acceptance criteria
- [ ] Free text and recipe text both produce structured, reviewable items
- [ ] Unparseable model output yields an empty result and a clear message — never a 500
- [ ] Two matching tool calls fail closed without falling back to prose
- [ ] Works with a non-tool-calling provider via the prose fallback
- [ ] New `ai_events` kind added and recorded per call
- [ ] Parsed items land in review, not directly on a saved list
- [ ] typecheck + lint + test green
