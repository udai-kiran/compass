> **Read [`UI.md`](./UI.md) first** — stack, the components that already exist, the three-edit nav rule, and the conventions this repo enforces. Do not add a UI or charting library.

**New nav group — all three edits from `UI.md` required.** Add a **Shopping** group (Lists, Cart, Pantry, Price Watch) to `NAV_GROUPS`, new names to the closed `IconName` union, and entries to `CommandPalette` `PAGES`.

**Files:** `src/routes/shopping/ListsPage.tsx`, `CapturePanel.tsx`, `src/lib/shopping-queries.ts`, plus the three nav files.

- **Lists** — create, rename, archive, add/edit/reorder items, mark bought.
- **Paste capture** — textarea → preview → commit, modelled on `src/routes/investments/MfImportPage.tsx` (the lightweight 2-step wizard), *not* the heavier 4-step import flow.
- **Photo capture** — extend the existing upload pattern (`FormData` + raw `fetch`, as in `TransactionDrawer.tsx`) with `capture="environment"` so mobile opens the camera. There is no camera code in this app today; this is greenfield.
- **Ambiguous items go to review, never silently resolved** — mirror the escape-hatch pattern from `InboxPage.tsx` so a wrong guess degrades instead of trapping the user.
