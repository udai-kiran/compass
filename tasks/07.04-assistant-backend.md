Chat endpoint running a tool-use loop where the model calls whitelisted internal service functions (spending summary, budget status, goal math, transaction search) — never raw SQL/DB access. Conversation state in Redis with TTL.

## Acceptance criteria
- [x] Tools are typed wrappers over existing services with per-tool input validation
- [x] Token/turn limits enforced; runaway loops cut off
- [x] Endpoint 404s cleanly when AI is disabled

## Implementation
`services/ai/tools.ts`: whitelisted, Zod-validated read-only wrappers over report/budget/insights/search/goals services — no raw SQL. `services/ai/assistant.ts` runs the tool loop capped at MAX_TURNS=5. `POST /api/ai/chat` streams SSE; 404 when disabled.
