EMI tracking as loan schedules on recurring templates (principal/interest split, remaining installments). Simple reward-points ledger per card (earn rate, manual adjustments, redemption log).

## Acceptance criteria
- [x] EMI view: remaining installments, total interest, payoff date
- [x] Reward balance per card with history
- [x] EMI instances land as transactions via the recurring engine

## Implementation
- Shared `standardEmiPaise` (reducing-balance installment) in `money.ts` — used by the API for the authoritative create and by the web form for a live preview. `CreateEmiSchema` in `wealth.ts`.
- `services/emis.ts`: `amortize` (per-installment interest/principal split → total interest + outstanding after N paid), `createEmi` (creates a monthly `kind="emi"` recurring template with the derived installment + an `emi_details` schedule in one transaction; `endDate` caps materialization at the tenure), `listEmis` (paid/remaining installments, total interest, outstanding, payoff date), `deleteEmi` (schedule removed; materialized installments stay).
- `routes/emis.ts`: GET/POST/DELETE `/api/emis`; POST materializes due installments immediately. Registered in `app.ts`. Pause/resume reuses `/api/recurring/:id`.
- Rewards ledger shipped with 5.1 (`reward_entries`, earn rate, manual +/− entries, balance on the card summary).
- Web: `routes/emis/EMIsPage.tsx` (progress `Meter`, installment/interest/outstanding/payoff, pause & delete, create form with live EMI preview) + `lib/emi-queries.ts`; new `/emis` route and "EMIs & Loans" nav item.
- Verified: ₹1,20,000 @ 13.5% × 12mo → ₹10,746/mo, 3 past installments auto-posted as `source=recurring` transactions, total interest reconciles (12×installment − principal), payoff 2027-03-15; pause and delete-preserves-history confirmed.
