The AI-assisted layer over the deterministic roadmap: explain the plan in plain language, name the tradeoffs, and answer follow-ups ("what if I retire two years earlier?").

**Every number comes from the services in 4.1/4.2 — the model explains, it never computes.** An LLM doing compound-interest arithmetic is exactly the failure mode to avoid; it will be confidently wrong. Feed it computed figures and let it do what it is actually good at: framing tradeoffs a spreadsheet cannot.

Reuse the existing AI path unchanged — per-user provider from `ai_settings`, forced tool-calling with an exact-name filter that fails closed on 2+ matches, prose fallback for ollama, `AiObserver` → `ai_events` (needs a new kind added to the closed enum). Follows the assistant tool-loop precedent in `services/ai/tools.ts`.

## Acceptance criteria
- [ ] Narrative grounded strictly in computed values; no figure originates in the model
- [ ] Tools expose the roadmap, allocation and instrument-category outputs read-only
- [ ] Works with AI disabled — the deterministic roadmap remains fully usable without narrative
- [ ] Unavailable or unparseable model output degrades to the plain plan, never an error page
- [ ] New `ai_events` kind added and recorded
- [ ] Never emits a named scheme/fund/AMC (carries the 4.2 rule into generated text, tested)
- [ ] typecheck + lint + test green
