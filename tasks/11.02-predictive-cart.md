`cart_drafts` — the app proposes a cart before you run out, from the pantry model plus learned rates.

**A draft is a proposal and nothing else.** It is never ordered, never auto-accepted, and never posted to the ledger. This mirrors `extracted_transactions`, which has never reached the ledger without an explicit accept, and is enforced by the same demo-mode mutation chokepoint.

Includes substitution suggestions when the usual brand spikes in price.

## Acceptance criteria
- [ ] Drafts generated on a schedule from pantry + rates, with each item's reason shown
- [ ] A draft is fully editable; removing an item teaches the model
- [ ] No draft can become an order or a ledger entry without explicit user action
- [ ] Substitution suggested on a price spike, with the price delta stated
- [ ] Draft generation is idempotent — repeated runs do not duplicate
- [ ] typecheck + lint + test green
