The core of the conversion. Today a transaction **is** a signed amount against one account (`transactions.accountId` + `amountPaise`, outflow negative), and an account balance is `accounts.openingBalancePaise + sum(amountPaise)` — two sources of truth for one number.

Replace it with postings:

- **`postings`** — `transaction_id`, `account_id`, `amount_paise`, `category_id`, `necessity`
- **`transactions`** becomes a header: date, `occurredAt`, merchant, notes, tags, source. **No `account_id`, no `amount_paise`.**
- **Invariant: postings sum to exactly zero per transaction.** Enforced in the service and asserted by property test, not merely hoped for.
- **System accounts** — `Expenses`, `Income`, `Opening Balances`. Category stays a *dimension on the posting*, not an account, so there is one Expenses account rather than a chart of accounts.
- **Balance becomes `sum(postings)` for an account** — one source of truth. `accounts.openingBalancePaise` and `transactions.is_opening` both disappear; an opening balance is a posting against `Opening Balances`.

**Signs become mechanical.** No "outflow is negative because we decided so" — a posting is positive or negative and the transaction balances. The semantic sign convention documented at `services/transactions.ts:22` stops being something anyone has to remember.

The production database is being recreated from scratch for 2.0.0, so **there is no backfill, no dual-write and no shadow period** — which is the entire reason this is tractable now and would not be later.

## Acceptance criteria
- [ ] `postings` table; `transactions` reduced to a header with no account or amount
- [ ] Zero-sum invariant enforced on write and covered by a **property test over generated postings**
- [ ] Account balance derived solely from postings; `openingBalancePaise` and `is_opening` removed
- [ ] System accounts seeded per user; not user-deletable
- [ ] Category and necessity carried on the posting, not the header
- [ ] Integer paise throughout; no rounding path can create or destroy a paisa
- [ ] Tables updated in `ALL_TABLES`/`USER_TABLES`
- [ ] typecheck + lint + test green
