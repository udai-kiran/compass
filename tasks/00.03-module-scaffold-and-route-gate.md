The safety harness that makes Phase 1 survivable, plus the module skeleton it migrates into.

**Route-table gate:** capture the current route table (`app.printRoutes()`) as a committed snapshot covering all 155 URL patterns across 39 route modules. A test asserts the live table matches the snapshot. Because prefixed plugins reintroduce paths indirectly, this is the single highest-value guard in the release — during Phase 1 the snapshot must not change at all.

**Module scaffold:** the `modules/<domain>/` layout (schema slice, services, routes, plugin entry) and the barrel wiring that re-exports every schema slice into one Drizzle instance, so `db/schema.ts` can become a barrel without changing generated SQL.

## Acceptance criteria
- [ ] Route snapshot committed; a test fails on any added, removed, or renamed route
- [ ] Module scaffold documented and proven by one trivial slice, with `npm run db:generate` producing **no** migration diff
- [ ] `services/backup.ts` `ALL_TABLES`/`USER_TABLES` still pass `backup.test.ts` after the barrel change
- [ ] Full suite green with zero URL changes
