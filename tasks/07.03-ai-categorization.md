AI is the **only** categorization assist — the deterministic rules engine (2.6) was dropped
(2026-07-14, user decision). Until this task ships, categories are set manually. For
uncategorized transactions: batch AI suggestions with confidence indicators; accept-all /
per-row confirm UI.

## Acceptance criteria
- [x] Suggestions offered for uncategorized transactions (manual categories are never overwritten)
- [x] Confidence shown; nothing auto-applies without user confirmation
- [x] Works in batch after an import and one-off from the transaction drawer

## Implementation
`services/ai/categorize.ts` only reads `category_id IS NULL` rows (manual categories untouchable). `POST /api/ai/categorize` (404 when off). UI: `AiCategorizePanel` on the Transactions page — per-row Accept + Accept-all, confidence %, nothing auto-applies.
