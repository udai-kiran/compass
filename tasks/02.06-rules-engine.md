**Dropped (2026-07-14, user decision):** no deterministic auto-classification. Categorization
is manual for now and will be AI-assisted in Phase 7 (task 7.3). Transactions keep explicit
`amountPaise` and `categoryId` fields; nothing fills the category automatically.

The engine was built and then removed: `category_rules` table (dropped in migration 0005),
rules service/routes, and the auto-apply hooks in `createTransaction` and import staging.
Merchant *name normalization* rules (2.5) are unaffected and remain in place.

## Acceptance criteria (obsolete)
- ~~Deterministic: same input always yields same category~~
- ~~Dry-run shows which existing transactions a new rule would hit~~
- ~~Rules apply during import preview, before commit~~
