`packages/ai`: capability-based `AiProvider` interface (`suggestCategories`, `generateSummary`, `chat`), `NullProvider` default when `AI_PROVIDER=none`. `GET /api/capabilities` tells the frontend what's enabled; UI hides all AI affordances when off. Lint rule: nothing outside `packages/ai` imports an AI SDK.

## Acceptance criteria
- [x] App fully functional with `AI_PROVIDER=none` (entire core test suite runs with NullProvider)
- [x] Capabilities endpoint drives UI visibility
- [x] No AI call sits on any core request path — AI has separate endpoints

## Implementation
`packages/ai`: `AiProvider` interface (`suggestCategories`/`generateSummary`/`chat`) + `NullProvider` (throws `AiDisabledError`). `createAiProvider(settings)` factory. App decorates `app.ai`; `GET /api/capabilities` reports `app.ai.enabled` (authoritative). ESLint bans AI SDKs outside `packages/ai`; providers use plain `fetch`. Full test suite runs with NullProvider.
