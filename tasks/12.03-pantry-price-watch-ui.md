> **Read [`UI.md`](./UI.md) first** — stack, the components that already exist, the three-edit nav rule, and the conventions this repo enforces. Do not add a UI or charting library.

**Files:** `src/routes/shopping/PantryPage.tsx`, `src/routes/shopping/PriceWatchPage.tsx`, `src/routes/shopping/pantry-view.ts` (+ `.test.ts`).

- **Pantry** — inferred stock levels per item. This is a *model of reality and it will drift*, so correction must be one tap ("I still have plenty") and visibly feed back into the learned rate. A pantry the user cannot correct is one they stop trusting after the first wrong prompt.
- **Price watch** — price history per item and source using `Sparkline` / `LineChart` from `viz.tsx`, with "buy now vs wait" **and its confidence**. Below the minimum observation count the UI must say the data is too thin rather than drawing a confident trend line from three points.
- **Price-honesty flags** — where a platform's "was ₹X" claim contradicts observed history, show the evidence, not just a badge.

## Acceptance criteria
- [ ] Pantry levels shown with their basis; correction is one interaction and is persistent
- [ ] Correction visibly affects the learned consumption rate
- [ ] Price history charted from `viz.tsx` primitives only
- [ ] Buy-now-vs-wait states confidence; refuses to advise on thin data rather than guessing
- [ ] Inflated "was" prices flagged with the observed history as evidence
- [ ] Empty pantry and no-observation states use `EmptyState`, not a blank page
- [ ] typecheck · lint · test · `npm run build -w apps/web` all pass
