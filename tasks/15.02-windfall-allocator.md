A bonus, appraisal arrear, maturity payout or gift arrives and gets absorbed into the current account within a month. Compass can answer where it should actually go — and almost all the machinery already exists once 5.2 lands.

Route a one-off amount through the multi-goal allocation engine as a lump sum rather than a monthly flow, and compare the genuine competing uses: fund the emergency-fund shortfall, close a lagging goal's gap, prepay debt (13.1), or invest per the goal glide path. Show what each option does to the goals that matter — *"₹2L: ₹50k tops up the emergency fund, ₹1.5L to the house deposit pulls it forward 7 months."*

Sequencing rules that should hold before anything is optimised: an unfunded emergency fund and any high-interest debt come first. Optimising a bonus into equity while a credit-card revolve is running is a straightforwardly wrong answer.

Detection can suggest — an unusually large credit is already detectable via existing anomaly detection — but a windfall is never allocated automatically.

## Acceptance criteria
- [ ] Lump sum allocated across goals via the 5.2 engine, not a separate parallel implementation
- [ ] Debt prepayment compared as a first-class option using 13.1
- [ ] Emergency-fund shortfall and high-interest debt prioritised ahead of optimisation
- [ ] Impact per option stated in goal terms (months pulled forward), not just rupees
- [ ] Large-credit detection suggests, never auto-allocates
- [ ] Tax implications flagged where the windfall is itself taxable
- [ ] Deterministic and unit-tested, including a windfall smaller than the emergency-fund gap
- [ ] typecheck + lint + test green
