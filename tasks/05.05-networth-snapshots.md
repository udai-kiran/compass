Nightly BullMQ job snapshots net worth (account balances + holding values − liabilities) into `net_worth_snapshots`. Historical chart, asset/liability breakdown, simple trend-based forecast.

## Acceptance criteria
- [x] Nightly snapshot idempotent (one per day)
- [x] History chart with asset/liability stacking
- [x] Backfill command estimates historical snapshots from ledger history

## Implementation
- `services/networth.ts`: `computeNetWorth(asOf)` (account balances by type + holding value; assets/liabilities split on sign), `snapshotAllUsers` (nightly, one row per user per day via the unique index → idempotent), `backfillSnapshots` (month-end estimates from ledger history, never overwrites observed days), `getNetWorthReport` (current + breakdown, history, 6-month linear forecast).
- Job: `networth.snapshot` scheduler at 00:30 + boot catch-up. `routes/networth.ts`: GET `/api/net-worth`, POST `/api/net-worth/backfill`.
- Web: `routes/networth/NetWorthPage.tsx` (net/assets/liabilities tiles, history `LineChart`, component breakdown, 6-month projection, "estimate last 12 months" backfill button).
- Verified: boot snapshot created today's point (idempotent), backfill produced 12 estimated months, holdings (₹1,70,000) included in the breakdown, forecast projects 6 month-ends.
