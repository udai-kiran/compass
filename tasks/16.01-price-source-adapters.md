**This task exists to answer the strongest objection to the whole shopping pillar.** The Codex review argued shopping should be deferred because crowdsourced and receipt-derived prices are sparse, stale and household-specific — *"a mathematically correct optimizer over bad data is still a bad feature."* That critique is correct as long as manual entry is the only input.

The existence of live comparators like [Comparify](https://comparify.pro/), covering ten platforms with real-time prices and delivery times, proves the data is obtainable. It does **not** tell us it is obtainable *legitimately at our layer*, and that distinction is the entire design problem.

Define one `PriceSourceAdapter` interface with several implementations, ranked by how defensible they are:

1. **Manual / receipt-derived** (already in 7.1) — always available, zero risk
2. **Official affiliate APIs** — Amazon PA-API, Flipkart Affiliate; ToS-compliant where they exist
3. **User-supplied third-party feed** — the user brings their own key or endpoint for a comparison service they already use
4. **Self-hosted community index** — opt-in, anonymized sharing between Compass instances
5. **Local scraping adapter** — **not shipped, not enabled, not endorsed.** The interface permits one; Compass does not provide it. A self-hosted user who runs their own is making their own decision about a platform's terms, which is materially different from us distributing a scraper.

Every observation records **which adapter produced it and when**, so downstream features can weight a live affiliate price differently from a six-week-old receipt. Adapters are disabled by default and configured per user, exactly like AI providers.

## Acceptance criteria
- [ ] One `PriceSourceAdapter` interface; adapters registered, not hardcoded into services
- [ ] Every `price_observation` records its adapter and observation time
- [ ] Confidence/freshness weighting available to 7.2, 7.5 and 8.x consumers
- [ ] All adapters disabled by default; configured per user, never via a global env key
- [ ] Adapter failure degrades to the next source; never breaks a page
- [ ] **No scraping implementation ships in this repo**; the extension point is documented, unimplemented and unendorsed
- [ ] Rate limiting and caching per adapter so a shared endpoint is not hammered
- [ ] typecheck + lint + test green
