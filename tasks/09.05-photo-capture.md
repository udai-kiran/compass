Photograph a handwritten or printed list and get the same structured, reviewable items as 4.4.

Server-side: image → `Storage` → the vision path from 3.1 → the same tool spec and Zod validation as paste-text. Client-side: extend the existing upload pattern (`FormData` → raw `fetch`, as in `TransactionDrawer.tsx:299-333`) with `capture="environment"` — there is no camera, dropzone or `FileReader` code in the app today.

## Acceptance criteria
- [ ] Photo upload → structured items, sharing the 4.4 parse/validate path
- [ ] Mobile camera capture works; desktop file picker still works
- [ ] Size and content-type limits enforced with a clear error
- [ ] A photo that yields nothing readable degrades to an empty review, not an error page
- [ ] Images stored via the `Storage` abstraction (S3 and disk both verified)
- [ ] typecheck + lint + test green
