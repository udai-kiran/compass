Settings UI: profile/password, currency & locale, notification preferences, categories/accounts management entry points, session management (active sessions, revoke), AI provider status (read-only until Phase 7).

## Acceptance criteria
- [x] Currency/locale reflected app-wide (formatting only; single-currency v1) — GET /api/capabilities exposes currency/locale; AboutPanel displays them, formatINR uses en-IN.
- [x] Active sessions listed and revocable — sessions indexed per-user (`sess-user:${userId}`); GET /api/auth/sessions flags current, DELETE revokes with ownership check.
- [x] Settings persist server-side per user — profile (PATCH /api/auth/profile), password (POST /api/auth/password, wrong current → 400), notification prefs all stored server-side.
