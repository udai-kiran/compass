Chat panel with streaming responses, suggested prompts ("Why was March expensive?", "Can I afford a ₹40k phone?"), and inline rendering of referenced transactions/budgets.

## Acceptance criteria
- [x] Entire panel absent when capabilities say AI is off
- [x] Streaming tokens render progressively
- [x] Tool results render as rich cards, not raw JSON

## Implementation
`components/Assistant.tsx`: floating panel mounted in AppLayout, rendered only when `capabilities.features.assistant`. Streams tokens progressively over SSE, tool-call chips as cards, suggested prompts. Raw tool JSON never reaches the UI.
