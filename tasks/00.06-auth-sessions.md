Register/login/logout with Argon2id password hashing. Session cookies (httpOnly, sameSite) stored in Redis with TTL. First-run bootstrap: if no user exists, show owner-account creation flow. Auth guard for all non-public routes.

## Acceptance criteria
- [x] Sessions persist across API restarts (live in Redis, not memory)
- [x] Logout revokes the session server-side
- [x] All API routes except health/login/bootstrap reject unauthenticated requests
