Central config module in the API: load `.env`, validate with Zod, fail fast on missing/invalid vars. All infra endpoints come from environment — never hardcoded.

Required vars (see `.env.example`): `DATABASE_URL` (Postgres at 192.168.2.196), `REDIS_URL` (Redis at 192.168.2.196), `SESSION_SECRET`, `PORT`, `AI_PROVIDER` (`none|anthropic|ollama`, default `none`).

## Acceptance criteria
- [x] API refuses to boot with a clear message if a required var is missing
- [x] `.env` is gitignored; `.env.example` documents every var
- [x] No IP/hostname literals anywhere in source — config module is the single source
