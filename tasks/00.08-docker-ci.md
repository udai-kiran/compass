Dockerfile for the API (tsc build, runs checked JS) and static build for web behind Caddy. `docker-compose.yml` for app services only — Postgres and Redis are external (192.168.2.196) and injected via env. GitHub Actions: typecheck, lint, test, build on PR.

## Acceptance criteria
- [x] `docker compose up` serves the app using `.env` values for DB/Redis
- [ ] CI runs green on a PR *(workflow in place — needs a GitHub remote and first PR)*
- [x] README quickstart: clone → set .env → compose up
