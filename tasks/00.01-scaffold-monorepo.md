Set up npm workspaces monorepo: `apps/web` (Vite + React + TS), `apps/api` (Fastify + TS), `packages/shared` (Zod schemas, types, money/date utils). Node 24 LTS, TypeScript ~5.9, strict ESM, `verbatimModuleSyntax`. Base tsconfig, ESLint + Prettier, `.nvmrc`, `engines` field.

## Acceptance criteria
- [x] `npm install` at root installs all workspaces
- [x] `npm run dev` starts web and api concurrently
- [x] `npm run typecheck && npm run lint` pass across workspaces
- [x] `packages/shared` importable from both apps with working types
