New `household` module. Tables `households` and `household_members`, plus an invite flow built on the existing open-signup path (`SIGNUP_ENABLED`).

Sharing is an **explicit grant, never implied by membership** — joining a household grants access to nothing by itself. Private is the default for every existing and new record, so behaviour for a solo user is completely unchanged.

## Acceptance criteria
- [ ] `households` + `household_members` added, with `ALL_TABLES`/`USER_TABLES` updated in the same change
- [ ] Invite → accept → member flow works; leaving a household revokes access cleanly
- [ ] A user with no household sees byte-identical behaviour to today (regression tested)
- [ ] Demo mode cannot create or join a household
- [ ] typecheck + lint + test green
